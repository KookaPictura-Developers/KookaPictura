## 1. Stroke decoder

- [x] 1.1 Add `StrokePosition { Outside, Inside, Center }` and `Stroke { enabled, present, blend_mode, color, opacity, size, position }` to a new `crates/pictura-render/src/layer_effects/strokes.rs`, beside the shadow and glow kinds.
- [x] 1.2 Add `pub fn decode_stroke(layer: &Layer) -> Option<Stroke>`: take the `lfx2` block via `Layer::extra_block`, require at least `8` bytes, hand `&data[4..]` to `pictura_codec::read_descriptor`, require the top-level object, find `FrFX` (an `Objc` with class id `FrFX`), and decode `enab`, `present`, `Md  ` (blend enum via `BlendMode::from_psd_key`, default/missing/unknown → `Normal`), `Clr `/`RGBC` `Rd `/`Grn `/`Bl  ` (default black), `Opct` (default 100), `Sz  ` (default 3; round then clamp to `1..=250` as `u32`), `Styl` (typeID `FStl`, `OutF`→Outside / `InsF`→Inside / `CtrF`→Center, missing/unknown→Outside), and `PntT` (typeID `FrFl`, `SClr`→solid, `GrFl`/`Ptrn`/unknown→`None`). Accept `UnitFloat` or `Double` for numeric keys. Any parse error, unknown data version, wrong type, a non-`BlnM`/`FStl`/`FrFl` typeID, a non-`RGBC` colour, or a non-finite value (including a finite `f64` that overflows `f32`) returns `None`; a finite out-of-range numeric is clamped (`opacity` `0..=100`, `size` rounded then clamped `1..=250`); never panic.
- [x] 1.3 Re-export `Stroke` and `StrokePosition` from `crates/pictura-render/src/layer_effects/mod.rs` and `crates/pictura-render/src/lib.rs`; add the module `ponytail:` ceiling comment for the deferred gradient/pattern fill, the ignored contour/anti-alias/overprint, and the colour-default divergence.
- [x] 1.4 Add decoder unit tests in `crates/pictura-render/src/tests/layer_effects/stroke.rs` using `pictura_codec::write_descriptor` with a `DescriptorBlock2` header (`1u32`, `16u32`): a full `FrFX` decodes to the expected `Stroke` including `Styl` `FStl`/`InsF` → `Inside`, `Styl` `FStl`/`CtrF` → `Center`, and `PntT` `FrFl`/`SClr`; a minimal `FrFX` takes the defaults (Normal, black, opacity 100, size 3, Outside); a `doub` (non-unit) numeric decodes; missing `lfx2`, missing `FrFX`, wrong data version, wrong-typed `Md  `, wrong `Md  `/`Styl`/`PntT` typeIDs, a non-solid `PntT` (`GrFl`/`Ptrn`), non-`RGBC` `Clr `, non-finite `Sz  `, and a truncated block each return `None` without panicking; `Sz  ` `1e30` clamps (size 250) and `1e300` rejects; `Opct` `1e30` clamps to 100.
