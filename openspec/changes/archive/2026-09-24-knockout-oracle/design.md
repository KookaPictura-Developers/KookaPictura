# Design: knockout-oracle

## Context

`scripts/generate-fixtures.py` authors every codec fixture with `psd-tools` and
writes it under `crates/pictura-codec/tests/fixtures/`; `knko` is
`Tag.KNOCKOUT_SETTING` mapped to a `ByteElement`, so a layer authors it with
`layer._record.tagged_blocks.set_data(Tag.KNOCKOUT_SETTING, 2)`.

`crates/pictura-render/tests/oracle.rs` is the compositor differential test:
committed raw interleaved-RGBA8 references (from ImageMagick via
`scripts/im_compose.py`) read without a codec, diffed with
`pictura_testkit::compare(actual, reference, tolerance)`.

`psd_tools/composite/composite.py` implements knockout; `_document_backdrop`
uses the **Background** layer (the bottom layer with no transparency channel) as
the deep-knockout target, and falls back to the initial backdrop otherwise. That
matches the CPU implementation's "bottom layer is the background" assumption
exactly when the fixture's bottom is a genuine Background, so the fixture must
be built with `PSDImage.new(..., color=...)` (a background, no alpha channel).

## Goals / Non-Goals

**Goals:**

- A committed `knockout.psd` with a real Background and a `Deep` knockout layer.
- A psd-tools-composite reference, diffed against `composite_rgba`.
- A semantic assertion (green punched through) independent of tolerance.

**Non-Goals:**

- Byte parity with Photoshop (still no Photoshop).
- Nested-group or clipping knockout (still open).

## Decisions

### D1. Fixture shape

`PSDImage.new("RGB", (8, 8), color=(255, 0, 0))` → Background red. Two
`create_pixel_layer`: green (0,255,0) and blue (0,0,255) with
`opacity = 128`. Set `blue._record.tagged_blocks.set_data(Tag.KNOCKOUT_SETTING, 2)`
(Deep). Save to `knockout.psd`. Author a `Shallow` sibling (`knko = 1`) only if
it is useful; at the document root both resolve to the background.

### D2. Reference generation

New `scripts/psd_knockout_reference.py` opens `knockout.psd`, calls
`psd.composite()`, converts to `RGBA`, and writes raw interleaved RGBA8 to
`crates/pictura-render/tests/fixtures/knockout_deep.rgba` (and `_shallow`). Raw
RGBA8 keeps the test codec-free, like `im_compose.py`.

### D3. The test

`crates/pictura-render/tests/knockout_oracle.rs`:

1. `read_psd` the committed `knockout.psd`; assert the top layer's `knockout`
   is `Knockout::Deep` (independent decode proof).
2. `composite_rgba(&doc)` → compare to `knockout_deep.rgba` with
   `pictura_testkit::compare` at a small tolerance (start at 1; our 8-bit
   rounding may differ by one from psd-tools' floor). Document the tolerance.
3. Assert the middle layer is punched through: at a covered pixel the green
   channel is below a small threshold (the semantic check).
4. Self-skip when `python3 -c "import psd_tools"` fails, mirroring
   `adjustment_oracle.rs`.

## Risks / Trade-offs

- [Rounding drift] → a 1-LSB tolerance is expected; if it is larger, the test
  fails and the discrepancy is reported, not masked.
- [Model divergence] → if psd-tools' knockout differs structurally from the CPU
  inference, the fixture surfaces it; the fix is a behavior change, out of scope
  here.
- [Reference regeneration] → the reference is regenerated by the script and must
  be committed; the test self-skips without psd-tools, and CI installs it.
