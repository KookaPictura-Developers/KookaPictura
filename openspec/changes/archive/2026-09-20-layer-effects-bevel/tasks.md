## 2. Bevel & Emboss renderer: a lit interior bevel above the content

- [x] 2.1 Add `composite_bevel_emboss(canvas, layer, doc, bevel)` to `bevel.rs`: early-return when the style is not `Inner` or the technique is not `Smooth`; clamp `size`/`soften`/`depth`/`altitude_deg`/`opacity` with `clamp_finite` (and the documented maxima), treat a non-finite `angle` as 0, compute `blur_support(r) = ceil(3·sigma_from_radius(r))`, and build `padded = pad_rect(source, blur_support(size) + blur_support(soften) + 1)`; early-out on an empty `source`/`padded`, an all-zero `M`, or both highlight and shadow opacity 0.
- [x] 2.2 Build `M` over `padded` with `content_matte` multiplied by `mask_alpha/255`, form the height field `H = blur_matte(M, size)`, compute the central-difference gradients `gx`/`gy`, the normal `N = normalize(-gx·scale, -gy·scale, 1)` with `scale = max(size,1)·depth/100`, and the light vector `L = (cos(alt)·cos(angle), -cos(alt)·sin(angle), sin(alt))`; the signed shading is `dot(N, L) - sin(alt)`, negated when `direction` is `Down`.
- [x] 2.3 Apply `Soften`: map the shading to `0..=1`, `blur_matte(.., soften)`, map back. For each pixel in `source`, form `hi = M · max(shading,0) · highlight.opacity/100` and `sh = M · max(-shading,0) · shadow.opacity/100`, and composite `sh` then `hi` above the content with `blend_parts` and their own colours/modes.
- [x] 2.4 Call bevel from `composite_layer_effects_above` in `mod.rs` when `enabled && present`, after Inner Glow and before Satin, keeping the shared group / destructive-adjustment skip. Every pixel outside the content rect is byte-identical to the no-effect composite; a hand-built struct cannot panic; a non-`Inner`/non-`Smooth` bevel and `depth` 0 are no-ops.
- [x] 2.5 Add decoder tests in `crates/pictura-render/src/tests/layer_effects/bevel.rs`: a full `ebbl` decodes to the expected `BevelEmboss` (style/technique/direction, depth, size, soften, angle, altitude, `uglg`, highlight and shadow mode/colour/opacity); a minimal `ebbl` takes the defaults (Inner, Smooth, Up, depth 100, size 5, soften 0, angle 120, altitude 30, `uglg` true, highlight Screen/white/75, shadow Multiply/black/75); `Doub` numerics decode; the style/technique/direction enums decode every value; a disabled `ebbl` decodes but renders nothing; missing `lfx2`, missing `ebbl`, wrong data version, wrong class id, a wrong-typed numeric, a wrong enum typeID, a non-`RGBC` colour, a non-finite numeric, and a truncated block return `None`; `srgR`/`blur`/`Sftn`/`Lald`/`hglO`/`sdwO` 1e30 clamp and 1e300 rejects.
- [x] 2.6 Add render tests (same file): the bevel is interior and every exterior pixel is byte-identical; two `angle_deg` values and two `altitude_deg` values change which interior edge is lit/darkened; a larger `size` widens the shaded band and a larger `soften` widens the transition; a larger `depth` increases the shading magnitude; `direction` `Up` and `Down` differ with the highlight/shadow swapped; highlight/shadow colour, opacity and a non-`Normal` mode change the result; a layer mask hides the bevel where zero; a small layer on a larger canvas leaves outside-the-rect pixels byte-identical; a non-`Inner` style and a non-`Smooth` technique are byte-identical to no effect; a disabled/absent bevel, `depth` 0, and a crafted non-finite bevel are bounded no-ops.
