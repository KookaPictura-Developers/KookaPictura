# Slice Tools (Slice and Slice Select)

- **Spec ID:** `TOOL-013` (Slice tool); `TOOL-014` (Slice Select tool)
- **Status:** `Draft`
- **Parity tier:** `Core` (web/HTML output on Linux; see Edge cases)
- **New in CS6:** `No` — Slice and Slice Select tools and the Save For Web & Devices workflow are carried over; CS6 changed little beyond generated-CSS output settings and the surrounding UI.
- **Depends on:** `10-workflow-io/web-export-and-slices.md`, `01-architecture/document-model.md` (`ARCH-002`), `02-ui-ux/toolbox-and-options-bar.md`, `TOOL-011`.

## CS6 behavior

Slices divide an image into smaller images reassembled on a web page using an
HTML table or CSS layers, letting the user assign different URL links per region
or optimize each region separately. Slices are exported and optimized with
`File > Save For Web & Devices`, which saves each slice as a separate file and
generates the HTML or CSS needed to display it. Source: CS6 reference,
"Slicing web pages".

### Slice taxonomy

- **By creation**: *user* slices (Slice tool), *layer-based* slices
  (`Layer > New Layer-based Slice`), *auto* slices (generated to fill the
  remainder). User/layer-based slices are drawn with solid lines and blue
  symbols; auto slices with dotted lines and gray symbols. Auto slices are
  regenerated whenever user/layer-based slices are added or edited.
- **By content type**: Table, Image, No Image (CS6 reference, "Slice types").
  The Slice Options dialog's **Type** menu offers Image and No Image (and Table
  in the export context); setting options on an auto slice promotes it to a
  user slice.
- **Subslices**: auto slices generated by overlapping slices; numbered, not
  individually selectable, regenerated when stacking order changes.
- Slices are numbered left-to-right, top-to-bottom from the upper-left; numbers
  update as the layout changes. Slice badges indicate Image content, No Image
  content, or layer-based origin.

### Slice tool

- Drag on the image to create a user slice. **Style** in the options bar:
  Normal (free proportions), Fixed Aspect Ratio (W:H), Fixed Size (pixel W/H).
- `Shift-drag` constrains to a square; `Alt`/`Option-drag` draws from center;
  Spacebar-drag repositions while creating; right-click opens the context menu.
- **Slices From Guides** creates slices from the document's guides and deletes
  any existing slices.
- **Layer-based slice** encompasses all pixel data in a layer and follows the
  layer when it moves or is edited; less flexible than user slices and must be
  promoted to be moved/combined/divided.
- **Promote** (Slice Select options bar) converts auto/layer-based slices to
  user slices; unlinking in Save For Web promotes an auto slice.

### Slice Select tool

- Click to select; `Shift-click` adds to the selection; click a visible section
  of an underlying slice when overlapping.
- **Move/resize** user slices; adjacent selected slices share edges. Numeric
  **X/Y/W/H** are editable in the Slice Options dialog (origin = ruler origin,
  default upper-left of image). Slices snap within **4 px** to guides, user
  slices, or other objects (per `View > Snap To`).
- **Divide** (Slice Select options bar, `Divide Slice` dialog) splits slices
  horizontally and/or vertically by *Slices Down/Across* count or *Pixels Per
  Slice* (remainder becomes another slice). Divided slices are always user
  slices; layer-based slices cannot be divided. `Preview` shows the result.
- **Duplicate**: `Alt`/`Option`-drag from inside the selection (always user
  slices; linked user slices stay linked).
- **Copy/paste**: `Edit > Copy` then `Edit > Paste` within an image, into
  another image, or into another application (e.g. Dreamweaver); copies all
  layers within the slice bounds. Cannot copy while a pixel/path selection is
  active.
- **Combine** slices via context menu `Combine Slices`; the result is a user
  slice sized to the bounding rectangle and takes the first slice's optimization
  settings. Layer-based slices cannot be combined.
- **Stacking order**: Bring To Front / Bring Forward / Send Backward / Send To
  Back (not for auto slices).
- **Align/Distribute** user slices via options-bar buttons (top/vertical
  center/bottom, left/horizontal center/right) to reduce auto slices and HTML
  size.
- **Delete**: `Backspace`/`Delete` on selected slices; `View > Clear Slices`
  deletes all user + layer-based slices. Deleting a layer-based slice does not
  delete its layer; deleting the layer deletes the slice. Auto slices cannot be
  deleted (one full-image auto slice remains if all others are removed).
- **Lock** all slices: `View > Lock Slice`.
- Toggle Slice/Slice Select with `Ctrl`/`Cmd`; `Ctrl`/`Cmd` also toggles in
  Save For Web.

### Slice Options dialog

Opened by double-clicking a slice with the Slice Select tool, or via the
options-bar **Slice Options** button (not available in Save For Web). Controls:
Type (Image/No Image/Table), Name (not for No Image), Dimensions X/Y/W/H,
Background Color (None/Matte/White/Black/Other), URL, Target
(`_blank`, `_self`, `_parent`, `_top`, or a named frame), Message Text, Alt
Tag/Alt, and — for No Image slices — HTML text plus horizontal and vertical
Cell Alignment (`Default`/`Left`/`Center`/`Right`;
`Default`/`Top`/`Baseline`/`Middle`/`Bottom`). `Text is HTML` is a Save For Web
option.

Photoshop does not render HTML text or background colors in the canvas; preview
in a browser is required.

### Output to web

`File > Save For Web & Devices`:

- Display tabs: Original, Optimized, 2-Up, 4-Up; per-slice optimization; link
  slices (GIF/PNG-8 linked slices share palette and dither to avoid seams);
  `Optimize To File Size`; Image Size tab (resize, interp, Constrain
  Proportions).
- Save Optimized As: Format = HTML + images / images only / HTML only; Slices
  menu = All Slices / Selected Slices; metadata menu (None / Copyright /
  Copyright and Contact Info / All Except Camera Info / All); `Convert to sRGB`
  (on by default).
- **Output Settings** — HTML set: Output XHTML, Tags Case, Attribute Case,
  Indent, Line Endings, UTF-8 encoding (Photoshop always UTF-8), Include
  Comments, Always Add Alt Attribute, Always Quote Attributes, Close All Tags,
  Include Zero Margins On Body Tag.
- **Slice output options** — Generate Table (HTML table) vs Generate CSS;
  Referenced By ID / Inline / By Class; Empty Cells (GIF IMG W&H, GIF TD W&H,
  NoWrap TD W&H); TD W&H (Always/Never/Auto); Spacer Cells
  (Auto/Auto Bottom/Always/Always Bottom/Never); Default Slice Naming.
- **Saving Files** set: File Naming, Filename Compatibility
  (Windows/macOS/UNIX), Put Images In Folder, Copy Background Image; Background
  set: View Document As Image/Background, Background Image, Color.

Slices are saved with the PSD (slice layout is document metadata); slice output
requires an export step.

## Algorithms & pipeline

- **Slice layout model**: a set of user and layer-based rectangles over the
  canvas; auto slices are the complement (a guillotine partition), subslices
  arise from overlaps. Numbers are assigned by sorting rectangle origins
  top-to-bottom then left-to-right.
- **Divide**: cut a slice into N equal spans (`Slices Down/Across`) or into
  fixed-width spans (`Pixels Per Slice`) with a trailing remainder slice.
- **Combine**: bounding rectangle of the selected slices; overlap resolution by
  stacking order.
- **Export**: for each slice, sample the canvas region (clip to slice bounds,
  `No Image` → no bitmap), encode with that slice's optimization settings,
  write file(s) named by the Default Slice Naming / File Naming rules, then emit
  an HTML table or absolutely/inline/class-positioned CSS. Linked slices share
  a GIF/PNG-8 palette and dither pattern.
- Behavioral parity only, algorithm TBD for the exact HTML/CSS emitter output
  templates; the CS6 reference documents the option semantics, not the byte
  templates.

- `SliceTool` / `SliceSelectTool` — on-canvas overlays for creating/selecting
  slices, with badges, numbering, dotted auto-slice lines, and a hover

- `SliceOptionsDialog` (`QDialog`) — all Slice Options fields; live validation
  for URL/target.
- `DivideSliceDialog` (`QDialog`) — horizontal/vertical, count vs pixels,

- `SaveForWebDialog` (`QDialog`) — tabs (Original/Optimized/2-Up/4-Up),

Widgets are preferred for the dense dialogs; the canvas overlays are scene
items.

## Data-model impact

- Document gains a `SliceLayout` (list of slices + links + numbering state),
  serialized with the PSD so slices round-trip.
- Layer-based slices reference a layer id; deleting the layer removes the
  slice.
- Undo granularity: each layout mutation (create, move/resize, divide, combine,
  promote, align, delete, lock) is one history state. Record shape: before/after
  slice layout diff (id, rect, options).
- Export is not undoable; it writes files only.
- Preferences: slice line color and show-slice-numbers live in the
  Guides/Grid/Slices preferences store.

## Edge cases

- **Overlapping slices** create subslices; selection must reach underlying
  slices via visible sections.
- **Layer-based slice** follows layer content; animating a layer across large
  areas can make the slice exceed useful size (CS6 warning).
- **Divide remainder**: a 100 px slice divided by 30 px yields 30/30/30/10.
- **Snap**: 4 px tolerance; disabled when slices are hidden (`View > Snap To >
  Slices` disabled). `Ctrl`/`Cmd+drag` temporarily disables edge snapping
  (from Crop tool key list; verify for slices).
- **No Image slices**: no bitmap; HTML text/`Text is HTML` previewed only in a
  browser; large text can affect exported layout.
- **Empty export**: if all slices removed, one full-image auto slice remains.
- **Color management**: export defaults `Convert to sRGB`; 16-bit is converted
  to 8-bit by Save For Web.
- **Huge documents/slice counts**: exporter must stream per-slice and support
  cancellation; HTML table layouts with many slices can explode in cell count —
  prefer CSS output.
- **Platform**: no Dreamweaver on Linux; copy/paste interop to external editors
  is a non-goal (paste to another image remains supported).
- **GPU-unavailable**: slice overlays render on CPU.

## Parity acceptance criteria

1. Given two non-overlapping user slices, the slice count equals 2 user + the
   auto complement, and numbering runs left-to-right, top-to-bottom, starting
   at the upper-left.
2. Given a 100×100 px slice divided "Pixels Per Slice" = 30 horizontally, the
   result is 30/30/30/10 px wide user slices.
3. Given `Slices From Guides` with two horizontal and two vertical guides, the
   layout matches the guide grid and prior slices are gone.
4. Given a slice with URL and Target `_blank`, exported HTML contains an
   `<img>`/CSS block whose anchor carries `target="_blank"` and the URL.
5. Given Generate CSS with Referenced = By ID, the exported page positions
   slices with ID-referenced styles and no HTML table.
6. Given two linked GIF slices, the exported files share an identical color
   table and dither pattern, and the link icon renders in the UI.
7. Given `View > Lock Slice`, slice drags do not change the layout.
8. Given `File > Save` as PSD then reopen, the slice layout and numbers are
   identical.
