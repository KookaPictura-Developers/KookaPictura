# Bundled font assets

`LiberationSans-Regular.ttf` is Liberation Sans, bundled as the deterministic
text-render fallback font. It is metric-compatible with Arial, which makes it a
defensible substitute for the proprietary families a Photoshop document usually
names.

- Source: the `ttf-liberation` package, `/usr/share/fonts/liberation/LiberationSans-Regular.ttf`.
- License: SIL Open Font License 1.1; see `LICENSES/LiberationSans-OFL.txt`.

Do not edit the font. To refresh or replace it, copy a new OFL/BSD-licensed
face and its license here, then update the roster note in `docs/dev/STATE.md`.
